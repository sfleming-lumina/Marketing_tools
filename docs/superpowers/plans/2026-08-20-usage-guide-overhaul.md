# Usage Guide Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reorganize `#guideDrawer`'s 12 guide sections into 11 fully-navigable, logically-grouped sections — anchoring every section in the TOC, merging the three decision-lifecycle tools into one section, documenting the AI assistant for the first time, adding one example to the densest Findings paragraph, and renaming four section titles — with zero product-behavior change.

**Architecture:** The entire change is one contiguous block of static markup inside `outputs/marketing_decision_tool.html` (`.guide-toc` plus twelve `.guide-section` `<div>`s, lines ~454–466). Because the table of contents and the section anchors it points to must stay mutually consistent at every commit, this plan replaces that whole block in a single atomic edit rather than incrementally — an intermediate state with a TOC link pointing at a not-yet-created anchor would be a broken, un-reviewable diff. A second, independent task then updates the `filterSummaryLabel`/`referenceLabel` unaffected — no such coupling exists elsewhere, so this is genuinely one task.

**Tech Stack:** Vanilla JS/HTML, no build step. Tests run against the Node-based fake-DOM harness at `work/verify_marketing_tool.js` (run via `node work/verify_marketing_tool.js` from the `Marketing_tools` repo root — there is no `package.json`).
